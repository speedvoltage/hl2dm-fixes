Source SDK PR #2171: selected fixes
=================================
Upstream author: azzyr
PR: https://github.com/ValveSoftware/source-sdk-2013/pull/2171
Reviewed head: 1fcfe5b449af631bd438ffbdf66acc1848471d2f
Integrated locally: 2026-11-05

Selected changes:
- hl2mp_bot.cpp and hl2mp_bot_manager.cpp: inclusive RandomInt upper bounds
  must be model count minus one, for DM and both TDM model lists.
- imageutils.cpp: decode 1/4-bit BMP pixels through their palette and avoid
  writing a second pixel past an odd-width 4-bit row.
- Client/server baseflex.h: pair new[] with delete[] for flex mappings.
- AI_ResponseSystem.cpp: initialize a copied Rule's context before SetContext
  releases the previous value.
- utlstring.cpp: use memmove for overlapping left-trim operations.
- BuildGroup.cpp: copy resource names before freeing stored names during reload;
  retain our existing path-ID alias guard.
- viewrender.cpp: pass the default visibility leaf (-1) as the second skybox
  BuildWorldRenderLists argument, and the cache flag as the third.

Additional BMP correction found during validation:
The original GetDIBits call fails on indexed images with ERROR_INVALID_PARAMETER
on Windows. LoadImage creates a DIB section, so retrieve its palette using
GetDIBColorTable while it is selected into a temporary DC, then restore the
previous object. Initialize the entire palette buffer and release the bitmap
on the affected error paths. This also repairs 8-bit BMP imports.
API reference: https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-getdibcolortable

Regression runner (after the normal Windows build):
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-sdk-runtime-fixes.ps1

It compiles the actual imageutils.cpp and links the built SDK libraries. Tests
compare all decoded pixels for 35 BMPs (1/4/8/24/32-bit, widths 1/2/3/7/8/9/17),
including custom palettes, row padding, orientation and alpha, plus both
CUtlString::TrimLeft overloads and empty/whitespace/overlapping cases.
